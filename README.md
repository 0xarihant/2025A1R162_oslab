## 📖 Repository Guide

Each experiment has its own directory containing the necessary documentation and practical materials.

- `README.md` – Explains the experiment's objective, requirements, procedure, and outcome.
- `program.txt` – Contains the commands, source code, or instructions used during the practical.
- `screenshots/` – Stores images captured while performing and testing the experiment.

## 💻 How to Explore

1. Navigate to the experiment you want to view.
2. Open its README file for the experiment overview and instructions.
3. Refer to `program.txt` for commands and implementation details.
4. Visit the screenshots folder to review the practical work.
